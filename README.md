# mini-dsl (arquivado)

Protótipo de Server Driven UI que deu origem ao **[Tanz SDUI](https://github.com/tanztecnologia/sdui)**.

O desenvolvimento continua lá:

- contrato protobuf único (`tanz.sdui.v1`);
- pacote Flutter `tanz_sdui` (interpretador);
- pacotes .NET `Tanz.Sdui` e `Tanz.Sdui.AspNetCore`, com API no estilo Flutter;
- galeria de exemplo com todos os widgets e testes de ponta a ponta.

O histórico do interpretador, dos protos e dos componentes foi preservado no
novo repositório. Este repositório fica apenas como referência.

| Pasta | Conteúdo |
|---|---|
| `backend/AstNET` | servidor .NET da loja de exemplo |
| `frontend/app_engine` | app Flutter com o interpretador original |
